# 无相路线与任务板

周数是粗略估算范围，不是承诺日期；状态必须以代码、测试和主代理验收为准。

| 阶段 | 估算 | 目标 | 状态 |
| --- | --- | --- | --- |
| M0 骨架 | 1–2 周 | SDK workspace、内部协议、runtime、React 白名单和 mock playground | 已完成 |
| M1 AI 闭环 | 2–4 周 | 服务端真实模型生成 schema、校验/有限修复、取消/超时、文本 fallback | 待开始 |
| M2 生态与流 | 2–5 周 | 优先一个生态 adapter，加入流式更新和指标 | 待开始 |
| M3 自托管与商业验证 | 3–6 周 | 自托管 alpha，验证组织治理/云边界和付费意愿 | 待开始 |

## M0 任务

| ID | 任务 | 依赖 | DoD | 状态 |
| --- | --- | --- | --- | --- |
| M0-01 | workspace 与 TypeScript 基础 | — | npm workspaces 可安装；各包 private/UNLICENSED；typecheck/build 命令可运行 | 已完成 |
| M0-02 | protocol `0.1` | M0-01 | 有 surfaceId、revision、节点树、action allowlist 语义；坏输入有可测试拒绝路径 | 已完成 |
| M0-03 | framework-agnostic runtime | M0-02 | 原子 replace、过期 event 拒绝、有限历史、只读 replay 测试通过 | 已完成 |
| M0-04 | React 白名单 renderer | M0-02, M0-03 | 九类组件可渲染；未知节点不能绕过 catalog；输入产生合法 event | 已完成 |
| M0-05 | playground mock 闭环 | M0-04 | 旅行偏好表单→结果→修改，已有值保留；无模型、预订、云 | 已完成 |
| M0-06 | 验证和文档同步 | M0-01–05 | 适当 test/typecheck/build 运行；文档与实际导出 API 核对；报告待核对项 | 已完成 |

## 不阻塞 M0 的待定项

模型供应商、云形态、生态 adapter、许可证、组件扩展、鉴权和收费方案都留到对应阶段；M0 先完成可运行 SDK 和可重复验证。
